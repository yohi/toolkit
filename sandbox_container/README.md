**ClaudeCode 開発環境 最終セットアップガイド**

このガイドは、セキュリティを確保しつつ、可能な限り少ない手順でDockerコンテナのサンドボックス環境をセットアップし、日々利用するための最終的な手順をまとめたものです。

**🏛️ 基本方針：コンテナと認証情報の分離**

この環境構築の最も重要な原則は、**「コンテナ（家）と認証情報（鍵）を完全に分離する」**ことです。認証情報をDockerイメージに焼き付けることは、家の設計図に鍵のありかを書き込むようなもので、非常に危険です。

そのため、コンテナ起動時にホストPC（あなたのPC）から認証情報ファイルのみを安全に「貸し出す」（マウントする）方式を採用します。

**STEP 1: 初回環境セットアップ (一度だけ実行)**

あなたのPCに、開発環境の設計図となるファイル一式 (Dockerfile, start-dev.sh) を準備します。以下のAかB、どちらか**好きな方法を一度だけ**実行してください。

**方法A：安全な git clone (強く推奨)**

最も安全で、プロフェッショナルな方法です。

# 1. このリポジトリをあなたのPCに複製します
# (リポジトリのURLは適宜変更してください)
git clone [https://github.com/yohi/sandbox.git](https://github.com/yohi/sandbox.git)

# 2. 作成されたディレクトリに移動します
cd sandbox

**方法B：便利な curl | sh (リスクを理解した上で)**

コマンド1行でセットアップが完了する便利な方法ですが、サプライチェーン攻撃のリスクを伴います。**作者であるあなた自身が、ご自身の責任で実行する場合にのみ**使用してください。

# このコマンドが、installer.shをダウンロードし、実行します
# (URLは適宜変更してください)
curl -sL [https://raw.githubusercontent.com/yohi/sandbox/main/installer.sh](https://raw.githubusercontent.com/yohi/sandbox/main/installer.sh) | sh

**STEP 2: 日々のサンドボックス起動 (繰り返し利用)**

初回セットアップが終われば、日々の作業はこれだけで完結します。

start-dev.sh があるディレクトリの中で、以下のコマンドを実行してください。

./start-dev.sh

**実行されること**

1.  (初回のみ) Dockerfile を元にDockerイメージが自動でビルドされます。
2.  あなたのPCにある ~/.claude ディレクトリから認証情報と設定ファイルが読み込まれます。
3.  認証済みの状態で、すぐに使えるサンドボックス環境が起動します。

**🗂️ 各ファイルの説明**

*   **README.md**: (このファイル) セットアップと利用方法を説明するガイドです。
*   **installer.sh**: (方法Bで使われる) 開発環境のファイル一式をあなたのPCに自動で作成するためのスクリプトです。
*   **Dockerfile**: サンドボックス環境の設計図。
